# 火瞳 · 全链路产品技术报告 — 叙事文档

## ① 用户意图对齐

- **目标受众**：重庆展会观众 / 投资人 / 技术评审 —— 需要快速理解产品全貌和技术深度
- **核心目标**：让观众相信「火瞳=视觉+数据双引擎的火锅AI运营中台」，记住「129项功能/43,569行代码/9大模块」，产生「这个团队有完整链路」的信任感
- **PPT长度**：16页（Hero 4页 = 25%，符合20-30%要求）
- **视觉调性**：科技深色、数据冲击、架构专业、节奏明快
- **内容边界**：
  - ✅ 必讲：市场机会 → 产品定位 → 129项功能 → 技术架构 → 详细设计 → 展会冲刺
  - ✅ 必讲：六层文档链路追溯（体现工程严谨性）
  - ⏳ 可选：竞品详细对比表（用精炼版替代）
  - ❌ 禁碰：具体代码片段、内部会议纪要细节、未验证数据
