## 颜色系统（浅色商务风 v2）

### 色板（4色 + 文本色）

| 角色 | 色值 | 用途 |
|:-----|:-----|:-----|
| **主色背景** | `#FFFFFF`（纯白） | 页面底色、大面积背景 |
| **辅色背景** | `#F1F5F9`（浅灰蓝） | 卡片背景、内容区分块、分隔区域 |
| **边框/分割** | `#E2E8F0`（中灰） | 卡片边框、分割线、表格线 |
| **强调色-蓝** | `#2563EB`（商务蓝） | 巨型数字、核心数据标注、CTA按钮、链接、主视觉锚点 |
| **强调色-暖** | `#D97706`（深琥珀） | 警示数据、里程碑日期、第二强调点 |
| **文本主色** | `#0F172A`（深墨蓝） | 标题、正文、核心文字 |
| **文本弱色** | `#64748B`（中性灰） | 辅助文字、脚注、页码、说明文字 |
| **成功绿** | `#059669` | 正向指标、已有功能标记 |
| **新增蓝** | `#3B82F6` | v1.1新增模块标记 |

### 色彩面积分配

| 色彩角色 | 常规页 | Hero页 |
|:---------|:------:|:------:|
| 主色背景(#FFF) | ≥65% | ≥50% |
| 辅色背景(#F1F5F9) | ≤25% | ≤30% |
| 强调色(蓝/暖) | ≤5% | ≤15% |
| 中性色(文本/灰/边框) | 剩余 | 剩余 |

### 渐变方案（浅色系）

| 渐变名 | 定义 | 使用位置 |
|:-------|:-----|:---------|
| `tech-gradient` | `linear-gradient(135deg, #EFF6FF 0%, #F0F9FF 50%, #EEF2FF 100%)` | 封面背景、架构页背景 |
| `blue-glow` | `linear-gradient(135deg, #2563EB 0%, #3B82F6 100%)` | 数字渐变、CTA按钮 |
| `warm-glow` | `linear-gradient(135deg, #D97706 0%, #EA580C 100%)` | 里程碑、警示数据 |
| `purple-glow` | `linear-gradient(135deg, #7C3AED 0%, #2563EB 100%)` | 详细设计章节背景 |
| `ending-glow` | `linear-gradient(135deg, #D97706 0%, #EA580C 100%)` | 结束页背景 |
| `section-header-bar` | `linear-gradient(90deg, #2563EB 0%, #3B82F6 50%, transparent 100%)` | 页面标题下方装饰线 |

### 半透明策略

- 大面积浅覆盖：`rgba(37,99,235,0.06)` — 卡片悬浮感
- 卡片阴影：`boxShadow: '0 2px 12px rgba(0,0,0,0.06)', border: '1px solid #E2E8F0'` — 浅色卡片标配
- 分隔线：`#E2E8F0` 实线或 `rgba(148,163,184,0.25)`
- Hero页文字蒙版：不需要（浅色底直接显示文字）
