### 2.1 逐条映射

| B6 供应商规则 | N07画像/N08评级/N09对账 | 40% | **过于抽象**：缺规格变更流程、退换货SOP、群内协同 | 🔴高 | 细化 N07-N09 + 新增 N20 供应商协同 |
| B7 岗位AI助理 | K06看板/K07日报/K24 AI建议 | 30% | **框架缺失**：无按角色分发的交互入口 | 🟡中 | 新增岗位助理框架(A01-A04) |

### 2.2 差距分级汇总

#### 🔴 高严重度（影响展会演示和核心价值）

**G1. 冻品供应链模块缺失**

会议明确冻品是核心管控重点，当前 PRD 仅有 K11(进货称重)和 K12(以劣充好)两项，远不够。

需新增：
- S01 货品主数据管理：统一名称/规格/品牌/价格，锁定标准
- S02 冻品收货验收：品牌规格比对、温度检测、品质评级
- S03 退换货流程：不合格品自动发起退换货单，群内通知
- S04 冻品温控追溯：从收货到入库到出库全链温度记录

**G2. 跨店库存调拨缺失**

会议提出连锁门店可跨店调配库存，PRD 完全无此功能。

需新增：
- N19 跨店库存调拨：临期预警→调拨建议→店长确认→调拨执行→库存同步

**G3. 供应商规则过于抽象**

会议给出了非常具体的供应商管理规则，PRD 的 N07-N09 远不够细。

需细化：
- N07 补：规格变更需提前N天反馈、变更审批流
- N08 补：退换货触发条件、退换货SOP、群内反馈机制
- N09 补：对账异常自动标记、群内协同确认
- 新增 N20：供应商协同群（消息通知、问题反馈、确认流程）

#### 🟡 中严重度（影响体验和效率）

**G4. 岗位AI助理框架缺失**

会议定位"每个岗位配备AI助理"，当前 PRD 是统一的 Dashboard + 日报，没有按角色分发的交互入口。

需新增：
- A01 店长助理：今日待办、异常汇总、决策建议
- A02 后厨助理：备货提醒、SOP纠偏、废料预警
- A03 采购助理：采购清单、供应商比价、到货跟踪
- A04 供应商端口：订单确认、品质反馈、退换货处理

**G5. 库位管理空白**

会议指出"整箱冻品拆放后盘点难度大"，PRD 无库位管理功能。

需新增：
- N21 库位管理：库位编码、拆箱追踪、可视化盘点、库位利用率

**G6. 后厨操作规范补充**

会议提到的"出品率管控"和"定点标识"在 PRD 中缺失。

需补：
- K35 出品率管控：按食材统计出品率，异常偏低自动告警
- K36 库位定点标识：食材存放位置标识，提升找货效率

#### 🟢 低严重度（基本对齐，小幅补充）

**G7. 采购周期因子缺失**

N01 预测引擎输入缺"采购周期"因子，会议明确提到需结合采购周期预估备货量。

建议：N01 输入补"采购周期"因子即可。

## 四、对路线图的影响

### 4.1 当前路线图

```
Sprint 0(2周) → Phase 1(M1-M6) → Phase 2(M6-M12) → Phase 3(M12-M18)
```

### 4.2 会议带来的变化

1. **10月展会**：需在 3 个月内完成可演示系统，相当于 Phase 1 的核心功能必须提前到 M3
2. **冻品供应链**：原 P1 的供应商模块需提前到 P0
3. **岗位助理**：新增的交互框架需在展会前完成至少 A01(店长)和 A02(后厨)
4. **融资铺垫**：展会演示效果直接影响融资，Demo 质量是关键

### 4.3 建议调整后路线图

```
Sprint 0(✅完成) → 展会冲刺(8-10月) → 展会亮相(10月) → 复盘优化(11-12月) → 融资扩张(2027Q1)
```

展会冲刺期需交付：
- 冻品供应链 S01-S03（P0）
- 岗位助理 A01-A03（P0）
- 视觉 P0 全量在椒江店真实运行
- 数据引擎 N01-N04 在椒江店真实运行
- Demo 场景脚本和演示数据
