## 3. 服务依赖关系

### 3.1 依赖关系图

```
Cloud Dashboard (:8098)
    │
    │ (读取门店数据)
    ▼
Edge UI (:9080) ◄──── Demo Web (:8080)
    │                      │
    │ (数据读写)            (静态展示)
    ▼                      ▼
product_master.json ◄──── expo_demo.db
    │
    │ (VLM推理)
    ▼
Jetson GPU/CPU
    │
    │ (HTTP抓拍)
    ▼
海康NVR (:80)
    │
    │ (IPC视频流)
    ▼
IPC-01 ~ IPC-07 (.103-.109)
```

### 3.2 启动顺序

```
1. 物理层: NVR + IPC → 通电自启
2. 网络层: Router → DHCP分配IP
3. Jetson层:
   a. 系统启动 (Ubuntu 20.04)
   b. 网络配置 (eth0获取IP)
   c. 启动Edge UI (:9080)
   d. 启动Demo Web (:8080)
4. 云端层:
   a. 腾讯云实例运行中
   b. Dashboard (:8098) 运行中
```

## 5. 安全边界

### 5.1 安全域划分

```
┌─────────────────────────────────────────────────────────┐
│  公网域 (Internet Zone)                                │
│                                                         │
│  • 用户浏览器                                          │
│  • Cloud Dashboard (:8098) ← 唯一对外暴露的服务        │
│                                                         │
│  安全措施:                                             │
│  • HTTPS + Session认证                                  │
│  • IP白名单 (可选)                                      │
│  • WAF防火墙 (腾讯云自带)                               │
└──────────────────────────┬──────────────────────────────┘
                           │ 仅允许HTTPS(8098)+SSH(22)
                           ▼
┌─────────────────────────────────────────────────────────┐
│  DMZ (半可信域)                                        │
│                                                         │
│  • 向日葵远程桌面 (受控通道)                             │
│                                                         │
│  安全措施:                                             │
│  • 双因素验证 (密码+验证码)                              │
│  • 操作日志审计                                         │
└──────────────────────────┬──────────────────────────────┘
                           │ VPN隧道
                           ▼
┌─────────────────────────────────────────────────────────┐
│  内网域 (Trusted Zone) — 椒江店                         │
│                                                         │
│  • Edge UI (:9080) ← L2 PIN认证                         │
│  • Demo Web (:8080) ← 无认证(仅展示)                    │
│  • NVR / IPC                                           │
│  • Jetson SSH (:22)                                    │
│                                                         │
│  安全措施:                                             │
│  • 物理隔离 (仅店内设备可访问)                           │
│  • L2 PIN 6位数字认证                                   │
│  • 敏感数据不外传                                       │
└─────────────────────────────────────────────────────────┘
```

### 5.2 防火墙规则矩阵

| 源 | 目标 | 端口 | 协议 | 动作 | 说明 |
|----|------|------|------|------|------|

| 办公网IP | Cloud | 22 | TCP | ALLOW | SSH管理 |
| 0.0.0.0/0 | Cloud | 其他 | ANY | DENY | 默认拒绝 |
| 192.168.5.0/24 | Jetson | 9080 | TCP | ALLOW | Edge UI内网访问 |
| 192.168.5.0/24 | Jetson | 8080 | TCP | ALLOW | Demo展示内网访问 |
| 192.168.5.0/24 | Jetson | 22 | TCP | ALLOW | SSH内网管理 |
| 192.168.5.0/24 | NVR | 80 | TCP | ALLOW | NVR Web界面 |

## 附录B: 环境变量配置

### B.1 Edge UI 环境变量

```bash
# /opt/hotpot-smart-ops/.env (建议创建)

# 服务配置
EDGE_UI_HOST=0.0.0.0
EDGE_UI_PORT=9080
EDGE_UI_WORKERS=2  # Uvicorn worker数

# 认证配置
DEFAULT_PIN=123456  # 🔴 生产环境必须修改!
SESSION_TIMEOUT=7200  # 2小时

# 数据路径
DATA_DIR=./edge/edge-ui/data
PRODUCT_DATA_FILE=${DATA_DIR}/product_master.json

# 日志配置
LOG_LEVEL=INFO
LOG_FILE=/var/log/hotpot/edge-ui.log

# NVR配置 (海康)
NVR_HOST=192.168.6.21
NVR_PORT=80
NVR_USER=admin
NVR_PASSWORD=hy898989  # 🔴 注意是8不是9!

# VLM配置
VLM_MODEL_PATH=/opt/hotpot-infer/models
VLM_DEVICE=cuda  # 或 cpu (降级模式)
```

### B.2 使用环境变量

```bash
# 加载环境变量
source /opt/hotpot-smart-ops/.env

# 启动时自动加载
export $(cat .env | xargs)
python3 -m edge.edge-ui.main
```
