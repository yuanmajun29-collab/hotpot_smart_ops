## 1. 产品定位

### 1.1 是什么

运行在**每台 Jetson 边缘盒子本地**的轻量 Web 配置中心，类似路由器管理页面。

安装人员/店长通过浏览器（手机或电脑）访问 `http://盒子IP:9080` 即可完成所有配置操作。

### 1.2 不是什么

| 不是 | 说明 |
|------|------|
| ❌ 云端 Dashboard | 已有 `hotpot_platform/dashboard/`（面向总部运维） |
| ❌ 手机原生 App | 后续迭代，当前用响应式 H5 替代 |
| ❌ 完整运营平台 | 只做「设备配置 + 状态监控」，不做业务分析 |

### 1.3 核心价值

```
Before: SSH → 敲命令 → 查日志 → 改配置 → 重启服务
After:  浏览器 → 点按钮 → 看状态 → 填表单 → 一键生效
```

**目标用户**：

| 用户 | 使用频率 | 核心场景 |
|------|:--------:|----------|
| 安装工程师 | 首次部署 | 初始化向导、摄像头配对、IoT接入 |
| 店长 | 月度巡检 | 查看状态、确认在线、基础重启 |
| 区域督导(潘总) | 不定期 | 多店状态巡检、异常诊断 |
| 远程技术支持 | 故障处理 | 日志查看、远程诊断、OTA升级 |

## 5. 安全机制

### 5.1 访问控制

| 层级 | 方案 | 说明 |
|------|------|------|
| L1 网络隔离 | 仅局域网可访问 | 默认监听 0.0.0.0:9080 但路由器ACL限制外网 |
| L2 简单认证 | 访问密码 | 首次访问需设置6位数字密码 |
| L3 会话管理 | Cookie + Token | 30分钟不活动自动登出 |
| L4 操作审计 | 关键操作记录 | 所有配置变更记录日志 |

### 5.2 API安全

- 所有写操作需要 CSRF Token
- 敏感信息（密码/API Key）传输时加密展示为 `••••••`
- OTA升级需要二次确认 + 版本校验
