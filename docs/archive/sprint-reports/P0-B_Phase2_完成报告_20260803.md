### ✅ Task #304: 建立数据同步机制

**交付物**: `edge/edge-ui/api/data_sync.py` (480行)

**架构设计**:
```
┌─────────────┐     HTTP/gRPC      ┌─────────────┐
│  Edge UI    │ ◄────────────────► │  Cloud Hub   │
│  (Jetson)   │                    │  (腾讯云)    │
│             │                    │             │
│ - JSON缓存  │                    │ - PostgreSQL│
│ - 离线队列  │                    │ - REST API  │
│ - 同步状态  │                    │ - 审计日志  │
└─────────────┘                    └─────────────┘
```

**核心类**: `DataSyncEngine`

**功能特性**:
1. **双向同步**
   - Push: 本地变更 → Hub (批量UPSERT)
   - Pull: Hub最新数据 → 本地缓存

2. **离线模式**
   - 检测到断网自动切换离线模式
   - 变更排队到 `.offline_queue.jsonl` (JSONL格式持久化)
   - 重连后自动批量同步
   - 最大重试3次，指数退避

3. **冲突解决策略**
   ```python
   class ConflictResolution(str, Enum):
       LOCAL_WINS = "local_wins"      # Edge优先
       REMOTE_WINS = "remote_wins"    # Hub优先
       MANUAL = "manual"              # 人工审核
       NEWEST = "newest"              # 最新时间戳优先 (默认)
   ```

4. **监控与回调**
   - 实时同步状态查询: `engine.get_status()`
   - 回调机制: on_sync_complete / on_conflict / on_error
   - 统计信息: total_synced, total_failed, queue_size, uptime

5. **全局单例**
   ```python
   from edge.edge_ui.api.data_sync import start_sync, stop_sync, get_sync_engine

   await start_sync(config)  # 启动
   engine = get_sync_engine()  # 获取实例
   await engine.queue_change("product_master", "FP-MW-001", "update", {...})
   await stop_sync()  # 停止
   ```

## 三、app.py集成细节

**修改位置**: `hotpot_platform/cloud/event_hub/app.py` 的 `startup()` 函数

**集成代码**:
```python
def startup() -> None:
    validate_deployment_profile()

    # ── P0-B Phase 2: 自动初始化审计Schema (零配置部署) ──
    if os.environ.get("HOTPOT_DATABASE_URL"):
        try:
            from hotpot_platform.cloud.event_hub.middleware.db_init import init_all_schemas
            init_results = init_all_schemas()
            if all(init_results.values()):
                print("[EventHub] ✅ P0-B 审计Schema初始化完成")
            else:
                print("[EventHub] ⚠️ P0-B 部分Schema初始化失败")
        except Exception as e:
            print(f"[EventHub] ⚠️ P0-B Schema初始化异常: {e} (非致命)")

    runtime.org_registry.apply_to_hub(runtime.hub)
    # ... 后续代码不变
```

**设计决策**:
- ✅ 非致命错误：Schema初始化失败不阻止Hub启动
- ✅ 条件执行：仅在设置HOTPOT_DATABASE_URL时才初始化（SQLite模式跳过）
- ✅ 详细日志：成功/失败/异常都有明确输出
