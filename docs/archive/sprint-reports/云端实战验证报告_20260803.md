## 3. 关键修复记录

### 3.1 db.py Schema同步问题 (已修复 🔧)
**问题**: Event Hub启动失败 `no such column: supplier_id`
**根因**: 
- `db.py` 使用内联Schema（旧版，缺少P0-C新表）
- `audit_schema.sql` 包含新版Schema（含supplier_id等字段）
- 两个Schema系统冲突导致索引创建失败

**解决方案**:
```python
# 新增 _exec_schema_with_fallback() 方法
def _exec_schema_with_fallback(self, conn, sql):
    """逐语句执行，自动跳过升级兼容性错误"""
    for stmt in statements:
        try:
            cursor.execute(stmt)
        except sqlite3.OperationalError as e:
            if "no such column" in str(e).lower():
                print(f"⚠️ 跳过 (升级兼容): {e}")
            else:
                raise

# 新增 _load_audit_schema() 方法
def _load_audit_schema(self, conn):
    """加载audit_schema.sql保持Schema同步"""
    pg_sql = Path("middleware/audit_schema.sql").read_text()
    sqlite_sql = _convert_pg_to_sqlite(pg_sql)
    self._exec_schema_with_fallback(conn, sqlite_sql)
```

**修复文件**: `hotpot_platform/cloud/event_hub/db.py` (+80行)
