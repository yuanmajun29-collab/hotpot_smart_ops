## 🔒 安全审计清单

### ✅ 已实现的安全措施

| 安全项 | 状态 | 实现方式 |
|--------|:----:|----------|
| **JWT签名算法** | ✅ | HS256 (HMAC-SHA256) |
| **PIN哈希存储** | ✅ | SHA256(salt + pin) |
| **速率限制** | ✅ | 5次失败 → 5分钟锁定 |
| **Token过期机制** | ✅ | 可配置 (默认24小时) |
| **唯一Token标识(jti)** | ✅ | 每次签发生成唯一ID |
| **Issuer声明(iss)** | ✅ | 固定为 "hotpot-platform" |
| **CORS限制** | ⚠️ | 开发环境允许全部 (生产环境需限制) |
| **Cookie安全属性** | ✅ | HttpOnly + SameSite=Strict |
| **敏感API强制认证** | ✅ | get_current_auth 依赖注入 |
| **日志记录** | ✅ | 登录成功/失败/限流触发均有日志 |

### ⚠️ 待生产环境加强项

| 安全项 | 当前状态 | 建议改进 |
|--------|----------|----------|
| **JWT Secret强度** | ⚠️ 开发环境默认密钥较短 | 生产环境使用 ≥ 256bit 随机密钥 |
| **HTTPS强制** | ⚠️ 开发环境HTTP | 生产环境强制HTTPS (HSTS) |
| **Token黑名单** | ❌ 未实现 | 登出后使Token失效 (Redis/DB) |
| **PIN暴力破解防护增强** | ⚠️ 仅有限流 | 可增加: 图形验证码 / 渐进延迟 |
| **多因素认证(MFA)** | ❌ 未实现 | 敏感操作可增加 TOTP/短信验证码 |

## 🏗️ 架构设计亮点

### 1. 双模式平滑迁移
```
Phase 1 (当前): dual模式共存
├── POST /api/v1/auth/jwt-login   ← 新增 (推荐)
├── POST /api/v1/auth/pin-login    ← 新增 (兼容)
├── POST /api/v1/auth/login        ← 保留 (旧版重定向到pin-login)
└── 两者输出统一: {access_token, token_type: bearer}
```

### 2. 统一认证上下文 (AuthContext)
```python
class AuthContext:
    authenticated: bool
    username: str          # 用户名
    role: str              # 角色 (12种RBAC角色)
    store_id: str          # 门店ID
    data_scope: List[str]  # 数据范围
    token_type: str        # "jwt" | "pin"
    login_mode: str        # "jwt" | "pin"

    @property
    def is_admin -> bool           # 是否管理员
    @property
    def can_manage_store -> bool   # 是否可管理门店
    def can_manage_specific_store(store_id) -> bool  # 特定门店权限
```

### 3. 兼容双服务器架构
```
auth_unified.py (核心逻辑)
    ↓
    ├── auth_adapter.py (http.server适配器)
    │   └── Edge UI server_v2.py (Python标准库HTTP)
    │
    └── event_hub_auth_integration.py (FastAPI集成)
        └── app.py (FastAPI应用)
```

### 4. 前端统一调用接口
```javascript
// HotpotAuth 对象 (localStorage存储JWT)
await HotpotAuth.jwtLogin('zhangdian', 'demo')  // JWT登录
await HotpotAuth.pinLogin('123456')               // PIN登录
await HotpotAuth.apiCall('/api/protected')         // 自动附加Bearer Token
HotpotAuth.isAuthenticated()                       // 检查登录状态
await HotpotAuth.logout()                          // 登出
```
