## 七、故障排查指南

### 7.1 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| `ModuleNotFoundError: pydantic` | python3.9无pydantic | `python3.9 -m pip install 'pydantic>=2.0'` |
| `ModuleNotFoundError: pytest` | 未安装pytest | `python3.9 -m pip install pytest` |
| 导入错误: `No module named X` | 用了错误的Python | 确保用 `python3.9` 而非 `python3` |
| SSH连接超时 | 网络问题 | 检查向日葵远程连接状态 |
| 磁盘空间不足 | 日志/缓存过多 | `du -sh /* | sort -h` 定位大文件 |

### 7.2 Pydantic V2 警告处理

当前有5个 Pydantic deprecation 警告（非阻塞）：
```
PydanticDeprecatedSince20: Support for class-based `config` is deprecated
```
这些是 `class Config` 写法的遗留警告，不影响运行。后续可统一改为 `ConfigDict`。
