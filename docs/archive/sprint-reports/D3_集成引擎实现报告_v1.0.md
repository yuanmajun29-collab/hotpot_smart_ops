## 1. 实现概述

### 目标
实现D1（冻品供应链）和D2（岗位AI助理）之间的事件驱动集成框架，打通5个核心集成点。

### 架构设计
```
┌─────────────────────────────────────────────────────┐
│                  IntegrationEngine                   │
│  (单例模式 + EventBus事件总线)                        │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ┌─────────┐    Events    ┌──────────────────────┐  │
│  │   D1    │ ──────────→  │         D2           │  │
│  │ 模块层   │              │    岗位AI助理        │  │
│  ├─────────┤              ├──────────────────────┤  │
│  │ S01产品  │──IP-1────→│ 采购建议增强          │  │
│  │ S02质检  │──IP-2────→│ 后厨任务推送          │  │
│  │ S03订单  │──IP-3────→│ 订单跟踪同步          │  │
│  │ S04供应商 │──IP-4────→│ 供应商门户            │  │
│  └─────────┘              │                      │  │
│                           │  ←────IP-5────────┤  │
│  ┌─────────┐              │ 建议接受→PO创建      │  │
│  │   D2    │ ──────────→ │ (核心集成点)         │  │
│  │ 动作层   │              └──────────────────────┘  │
│  └─────────┘                                         │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 2. 核心组件

### 2.1 集成引擎 (`integration_engine.py`)

**路径**: `hotpot_platform/cloud/integration/integration_engine.py`
**规模**: ~450行代码

#### 关键类

| 类名 | 职责 | 特性 |
|------|------|------|
| `IntegrationEvent` | 事件类型枚举 | 12种事件类型（D1→D2: 8种, D2→D1: 4种） |
| `Event` | 事件对象 | 包含event_type/payload/timestamp/event_id |
| `EventBus` | 事件总线 | 同步发布、优先级支持、异常隔离、历史记录(100条) |
| `IntegrationEngine` | 集成引擎 | 单例模式、5个IP处理器注册、metrics指标 |

#### 核心方法

```python
# 初始化
engine = IntegrationEngine.get_instance()
engine.initialize(manager=SupplyChainManager)

# 发布事件（便捷方法）
engine.on_product_updated(sku="FP-HNRC-001")
engine.on_receiving_approved(record_id="RR-xxx", has_d_grade=True)
engine.on_po_status_changed(po_id="PO-001", old_status="draft", new_status="submitted")
engine.on_supplier_score_updated(supplier_id="SUP-001", score_data={...})
engine.on_suggestion_accepted(suggestion_id="SUG-001")  # 🎯 核心！

# 查询指标
metrics = engine.get_metrics()
event_log = engine.get_event_log()
```

## 3. 五大集成点详解

### IP-1: D1产品数据 → D2采购建议 ✅

**触发条件**: 产品数据变更时（每日自动触发）
**增强内容**:
- 基于真实消耗数据计算日均销量（从历史PO统计）
- 智能选择最佳供应商（A级优先，综合评分最高）
- 置信度计算：0.75 + (评分/100)×0.2
- 客流因子：工作日×1.1 / 周末×1.3

**数据流**:
```
ProductMaster._product_cache
    ↓ _calculate_daily_consumption()
日均消耗Map {sku: daily_avg}
    ↓ _find_best_supplier_for_sku()
最佳供应商 (id, name, score)
    ↓ _generate_suggestions() [增强版]
Purchase Suggestion (含action_params)
    ↓ Dashboard展示
A03 采购助理面板
```

### IP-2: D1质检结果 → D2后厨任务 ✅

**触发条件**: 收货审批通过时（特别是部分通过）
**核心逻辑**:
- 检测D级品质品项
- 自动生成urgent优先级后厨任务
- target_role=chef_head
- 2小时due_at

**事件链**:
```
S02 approve/partial_approve()
  → publish(D1_RECEIVING_APPROVED, has_d_grade=True)
    → IP-2 handler: create_kitchen_task_for_d_grade()
      → Task Cache更新
        → A02 后厨助理面板刷新
```

### IP-3: D1采购订单 → D2订单跟踪 ✅

**触发条件**: PO状态变更时（draft→submitted→confirmed→cancelled）
**联动效果**:
- submitted状态: 自动生成店长确认待办
- confirmed/cancelled状态: 更新跟踪面板状态
- received状态: 回写收货进度

**关键代码**:
```python
def submit_po(po_number):
    # ...原有逻辑...
    engine.on_po_status_changed(po_id, "draft", "submitted")
    # → 自动调用 generate_po_confirmation_task()
```

### IP-4: D1供应商评分 → D2供应商门户 ✅

**触发条件**: 评分调整/自动计算后
**预警规则**:
- score < 70: 生成high/urgent预警待办
- grade = D: 提升为urgent
- target_role: purchaser 或 store_manager

**数据同步**:
```
SupplierScore._score_cache
  → on_supplier_score_updated(score_data)
    → generate_supplier_alert_task()
      → Task Cache + Supplier Portal KPIs
```

### IP-5: D2建议接受 → D1采购订单创建 🎯 **核心**

**触发条件**: 用户点击"采纳"AI采购建议
**完整流程**:
```
用户操作: 点击"采纳建议"
  → assistant_api.accept_suggestion(suggestion_id)
    → SupplyChainManager.accept_suggestion()
      → 标记 is_accepted=True
      → 🎯 publish(D2_SUGGESTION_ACCEPTED)  [新增]
        → IP-5 handler执行:
          1. get_suggestion_detail() 获取建议详情
          2. 验证 suggestion_type == "purchase_order"
          3. create_po_from_suggestion():
             a. 验证SKU存在性
             b. 选择最佳供应商（或使用指定供应商）
             c. 计算单价（最近采购价/标准价）
             d. 创建PO (status=draft)
             e. 持久化到 _po_cache
             f. metadata标记 source=ai_suggestion
          4. publish(D1_PO_CREATED)  [联动IP-3]
            → PO跟踪面板自动刷新
```

**创建的PO示例**:
```json
{
  "order_no": "PO-20260801-005",
  "supplier_name": "杭州冻品供应链",
  "items": [{"sku": "FP-HNRC-001", "product_name": "肥牛卷", "qty": 20, "unit_price": 95}],
  "total_amount": 1900,
  "status": "draft",
  "metadata": {
    "source": "ai_suggestion",
    "suggestion_id": "SUG-20260801-003",
    "auto_generated": true
  }
}
```
