## 🎯 展会演示建议流程

### 时间分配 (总计15分钟)

```
00:00-01:00 开场 + 系统介绍 (1分钟)
01:00-03:00 S1 后厨之眼 (2分钟) ⭐ 视觉冲击
03:00-06:00 S2 算得清的订货 (3分钟) ⭐ 数据引擎
06:00-09:00 S3 冻品供应链 (3分钟)   供应链管控
09:00-11:00 S4 岗位AI助理 (2分钟)  ⭐ AI价值
11:00-13:00 S5 连锁看板 (2分钟)   ROI展示
13:00-15:00 IP-5 Gateway流程 (2分钟) ⭐⭐ 核心亮点 (合规性)
15:00-∞    Q&A互动
```

### 重点展示内容

1. **技术先进性**
   - 边缘AI推理 (Jetson实时处理)
   - 双引擎架构 (视觉 + 数据)
   - Agent Gateway创新 (行业首创)

2. **业务价值**
   - 年省 ≥¥150,000 (2家店实测)
   - 损耗降低 55% (vs 行业平均15%)
   - MAPE 10.6% (预测准确率行业领先)

3. **合规性保证** (IP-5重点)
   - "AI建议 → 人确认 → 执行" 三步走
   - 完整审计追踪 (who/when/what/why)
   - 符合餐饮行业监管要求
