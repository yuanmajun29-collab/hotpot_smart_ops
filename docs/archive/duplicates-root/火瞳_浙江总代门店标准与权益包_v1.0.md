## 二、门店准入标准

### 2.1 硬件准入

| 设备 | 最低要求 | 推荐配置 | 说明 |
|------|---------|---------|------|
| 边缘AI设备 | Jetson Orin Nano 8GB | Jetson Orin NX 16GB | 运行YOLO+CLIP+VLM推理管线 |
| 后厨摄像头 | 1路 1080p IPC（支持RTSP） | 2路（废料区+出品区） | 用于废料检测+出品质检 |
| 前厅摄像头 | 1路 1080p IPC（支持RTSP） | 2路（大堂+包厢区） | 用于桌态检测+翻台分析 |

- 新增菜品及时录入成本表
- 停售菜品标记为inactive

### 8.3 供应商评分刷新（每月）

- 从成本分析数据自动提取供应商指标
- 5维评分自动计算
- 评分变化>10%触发人工复核

### 8.4 预测模型迭代（每季度）

- 评估L2 SARIMA是否值得引入（当前L1+因子更优）
- 数据量>90天后尝试L3 LightGBM
- MAPE持续>25%时触发模型重训练
