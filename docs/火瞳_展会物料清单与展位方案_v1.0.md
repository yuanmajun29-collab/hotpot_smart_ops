### 2.2 预检测试项

```
□ Jetson开机测试（冷启动时间<60秒）
□ 网络连接测试（WiFi/有线双通）
□ Web UI访问测试（http://localhost:8080）
□ 数据初始化测试（POST /api/init, <30秒）
□ 全场景运行测试（POST /api/run-all, 全部通过）
□ 大屏显示测试（分辨率适配、字体清晰）
□ 场景切换流畅性（切换延迟<2秒）
□ 连续运行稳定性（至少1小时无异常）
□ 断电重启恢复测试（重启后自动拉起服务）
```

### 4.2 各区域说明

#### A. 主演示区（核心区域）

**位置**: 展位中央偏后
**构成**: 55寸+大屏 + Jetson边缘盒子（隐藏在屏后或桌下）
**功能**: 
- 循环播放欢迎界面（无人时自动播放产品介绍视频）
- 演示时切换到Web UI实时操作
- 建议大屏高度1.4-1.6m（观众站立视线舒适区）

**关键参数**:
- 屏幕亮度：展厅通常较亮，建议≥400nit
- 视角：178°广角（侧面观众也能看清）
- 音响：可选配小音箱（讲解声音放大）

#### B. 操作台区

**位置**: 大屏正前方，距屏幕80cm-100cm
**构成**: 小桌子(60cm×40cm) + 笔记本 + 键盘鼠标
**功能**:
- 主讲人操作设备
- 建议桌面整洁，只放必要设备
- 可铺深色桌布（藏线缆）

**注意事项**:
- 线缆从桌面背面走，正面看不到
- 键盘鼠标无线化，减少束缚
- 笔记本屏幕朝向主讲人（不要让观众看到）

#### C. 资料台/洽谈区

**位置**: 展位入口一侧或前方
**构成**: 长条桌(120cm×45cm) + 椅子×2-3
**功能**:
- 放置宣传资料（宣传册、DM单）
- 名片盒（双层：自己的+收集的）
- 二维码立牌（醒目位置）
- 小礼品（如有）
- 深度洽谈座位

**物料摆放原则**:
- 宣传册竖放，封面朝外
- DM单平叠，方便取阅
- 名片放在右手边（方便参观者自取）
- 二维码放在最显眼的位置（配合"扫码领取Demo体验"话术）

#### D. 引流区（入口两侧）

**构成**: 易拉宝/X展架 × 2
**内容**:
- 左侧：产品主视觉（"火瞳——让火锅店运营看得见、算得清"）
- 右侧：核心价值（"AI预测MAPE 10.6% | 年省¥150,000+/店"）
