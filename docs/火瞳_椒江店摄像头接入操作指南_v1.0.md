## 三、操作步骤

### Step 1：登录海康 NVR 管理界面

1. 打开浏览器，访问：**http://192.168.5.254**
2. 输入账号密码：
   - 用户名: `admin`
   - 密码: `hy898989`
3. 首次登录可能需要安装插件（推荐使用 IE 或 Chrome + IE Tab）

> ⚠️ 如果无法打开，请确认：
> - 电脑和 NVR 在同一局域网（连接椒江店 WiFi 或网线）
> - 防火墙未拦截 80 端口

### Step 2：开启摄像头 RTSP 服务

**方法 A：通过 NVR 界面开启（推荐）**

1. 登录 NVR 后，点击顶部菜单 **「配置」** → **「视频音频」**
2. 找到 **「视频编码」** 或 **「流媒体」** 设置
3. 对每个摄像头通道：
   - 选择 **「主码流」**
   - 编码格式选 **H.264**（兼容性最好）
   - 分辨率 **1920×1080**
   - 帧率 **15-25 fps**
4. 找到 **「RTSP」** 设置项：
   - ✅ 勾选 **「启用 RTSP」**
   - 端口默认 **554**（如被占用可改 8554）
   - 认证方式选 **「基本认证」**
5. 点击 **「保存」** → **「应用」**

**方法 B：通过单个摄像头 Web 界面开启**

如果 NVR 不支持统一设置，需要逐台登录摄像头：

| 摄像头 | IP地址 | 用途 |
|--------|--------|------|
| 收银台 | 192.168.5.100 | 客流统计 |
| 就餐区 | 192.168.5.101 | 客流+翻台 |
| 备餐废弃区 | 192.168.5.103 | **核心AI场景** |
| 炒制工位 | 192.168.5.104 | SOP合规 |
| 食材存储区 | 192.168.5.105 | 来料验收 |
| 出菜口 | 192.168.5.106 | 出菜统计 |
| 后门 | 192.168.5.108 | 送货记录 |

对每台摄像头：
1. 访问 `http://192.168.5.xxx` （xxx = 上述 IP 最后一段）
2. 用 `admin / hy898989` 登录
3. 进入 **配置** → **网络** → **高级配置** → **集成协议**
4. 开启 **RTSP**，端口 554
5. 保存并重启摄像头

### Step 3：验证 RTSP 流可用性

在 Jetson 上执行验证命令：

```bash
# SSH 到 Jetson
ssh root@172.16.1.60

# 验证核心摄像头（备餐废弃区）的 RTSP 流
ffmpeg -rtsp_transport tcp \
  -i "rtsp://admin:hy898989@192.168.5.254:554/Streaming/Channels/301" \
  -t 5 -f null - -

# 如果看到 "Video: h264" 字样说明成功！
# 常见输出示例:
#   Stream #0:0: Video: h264 (High), yuv420p(progressive), 1920x1080...
```

**快速批量验证脚本**（在 Jetson 上执行）：

```bash
#!/bin/bash
# rtsp_verify.sh - 批量验证所有摄像头 RTSP
NVR="192.168.5.254"
USER="admin"
PWD="hy898989"

declare -A CHANNELS=(
  ["收银台"]="101"
  ["就餐区"]="201"
  ["备餐废弃区"]="301"
  ["炒制工位"]="302"
  ["食材存储区"]="303"
  ["出菜口"]="304"
)

for NAME in "${!CHANNELS[@]}"; do
  CH="${CHANNELS[$NAME]}"
  URL="rtsp://${USER}:${PWD}@${NVR}:554/Streaming/Channels/${CH}"
  echo -n "  ${NAME} (${CH}): "
  timeout 10 ffmpeg -rtsp_transport tcp -i "$URL" -t 2 -f null - -y 2>&1 | grep -q "Video:" && echo "✅ OK" || echo "❌ FAIL"
done
```

### Step 5：启动服务

```bash
# SSH 到 Jetson
ssh root@172.16.1.60

# 1. 启动 Edge Agent（API服务 :9100）
cd /opt/hotpot-smart-ops
nohup python3 -m edge.agent.server > /tmp/hotpot-agent.log 2>&1 &
echo "Agent PID: $!"

# 2. 启动 RTSP 抓帧器
nohup python3 -m edge.kitchen.capture.ipc_frame_grabber \
  --config edge/common/config/ipc_config_jiaojiang.yml \
  > /tmp/ipc-grabber.log 2>&1 &
echo "Grabber PID: $!"

# 3. 启动推理 Pipeline
nohup python3 -m edge.kitchen.inference.pipeline \
  --config edge/common/config/pipeline_config_jiaojiang.yml \
  > /tmp/hotpot-pipeline.log 2>&1 &
echo "Pipeline PID: $!"

# 4. 验证所有服务运行中
sleep 3
ps aux | grep -E "agent.server|ipc_grabber|pipeline" | grep -v grep

# 5. 验证 API 可访问
curl http://127.0.0.1:9100/health
curl http://127.0.0.1:9100/debug/engine
```

## 四、常见问题排查

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 无法打开 192.168.5.254 | 不在同一网段 | 连接椒江店 WiFi 或用网线直连 |
| 登录提示密码错误 | 密码已修改 | 联系安装人员重置密码 |
| RTSP 开启后仍无法连接 | 防火墙拦截 | 在 NVR 防火墙规则中放行 554 端口 |
| ffmpeg 提示 401 Unauthorized | 凭据不匹配 | 确认 admin/hy898989 是正确的摄像头密码 |
| Jetson 无法 ping 通摄像头 | VLAN 隔离 | 联系网络管理员将 Jetson 加入 IPC VLAN |
| 视频流卡顿/延迟高 | 码率过高 | 在 NVR 中将子码流改为 720p/2Mbps |

## 五、海康威视 RTSP 地址格式参考

```
标准格式: rtsp://用户名:密码@NVR_IP:端口/Streaming/Channels/通道号01

通道号规则:
  1xx = 第1路摄像头主码流 (101=主, 102=子)
  2xx = 第2路摄像头
  3xx = 第3路摄像头（备餐废弃区=301）
  ...
  Nxx = 第N路摄像头
```
