## 4. 展会突发情况应急预案

### 4.1 技术故障处理
| 故障现象 | 可能原因 | 应急方案 | 处理时间 |
|----------|----------|----------|:--------:|
| Edge UI无法访问 | Jetson断网/宕机 | 重启Jetson + 向日葵远程 | 5min |
| 摄像头画面黑屏 | IPC断电/网络中断 | 切换到预录视频Demo | 2min |
| API响应超时 | 数据库锁死 | 重启Event Hub服务 | 3min |
| 登录页面空白 | 前端资源加载失败 | 检查Nginx/静态文件路径 | 2min |
| JWT Token过期 | 演示时间过长 | 刷新页面重新登录 | 30s |

### 4.2 演示内容调整
**如果某个场景无法展示**:
1. **D1冻品供应链不可用** → 重点展示D2岗位AI助理（离线模式有本地缓存）
2. **D2 AI对话卡顿** → 切换到预录视频 + 口述补充
3. **P0-C溯源数据缺失** → 使用截图PPT备份方案
4. **整个系统不可用** → 启用本地录屏视频 + 架构图讲解

### 4.3 网络环境保障
- **主方案**: 椒江店Jetson局域网直连（不依赖外网）
- **备用方案**: 4G/5G移动热点
- **降级方案**: 纯离线模式（预加载所有数据）

### 4.4 硬件设备清单
