## 1. 概述

### 1.1 目的

集中记录系统中所有数据表/模型的字段定义，作为开发和维护的权威参考。

### 1.2 命名约定

| 类型 | 约定 | 示例 |
|------|------|------|
| 表名/模型名 | PascalCase | `ProductMaster`, `ReceivingRecord` |
| 字段名 | snake_case | `unit_price`, `created_at` |
| 枚举值 | UPPER_SNAKE | `ACTIVE`, `DRAFT` |
| 常量 | UPPER_SNAKE | `MAX_PAGE_SIZE` |

## 2. 数据模型清单

### 2.1 供应链模块 (supply_chain)

#### 2.1.1 ProductMaster — 货品主数据

| 字段名 | 数据类型 | 长度/范围 | 约束 | 默认值 | 说明 |
|--------|----------|-----------|------|--------|------|
| sku_code | string | 2-30 | PK, 唯一, 大写 | - | SKU编码 |
| name | string | 1-50 | 必填 | - | 货品名称 |
| specification | string | 0-50 | 必填 | - | 规格型号 |
| brand | string | 0-30 | 必填 | - | 品牌 |
| unit_price | float | ≥0 | 必填 | - | 标准采购价(元) |
| unit | string | - | 可选 | "份" | 计量单位 |
| category | string | - | 必填, FK | - | 品类分类编码 |
| supplier_id | string? | - | 可选 | None | 默认供应商ID |
| supplier_name | string? | - | 可选 | None | 冗余供应商名称 |
| image_url | string? | - | 可选 | None | 产品图片URL |
| location_code | string? | - | 可选 | None | 库位编码 |
| location_name | string? | - | 可选 | None | 库位名称 |
| storage_area | string? | - | 可选 | None | 存放区域 |
| shelf_life_days | int? | ≥1 | 可选 | None | 保质期(天) |
| min_stock_qty | float? | ≥0 | 可选 | None | 安全库存量 |
| tags | string[] | - | 可选 | [] | 标签列表 |
| status | enum | 见枚举 | 可选 | "draft" | 状态 |
| locked | bool | - | 可选 | False | 是否锁定 |
| version | int | ≥1 | 可选 | 1 | 版本号 |
| created_by | string? | - | 自动 | None | 创建人 |
| created_at | datetime? | - | 自动 | None | 创建时间 |
| updated_by | string? | - | 自动 | None | 更新人 |
| updated_at | datetime? | - | 自动 | None | 更新时间 |
| approval_status | enum | 见枚举 | 可选 | "none" | 审批状态 |
| approval_notes | string? | - | 可选 | None | 审批意见 |

**索引**:
- `UNIQUE (sku_code)`
- `INDEX (category, status)` — 复合索引用于列表查询
- `INDEX (supplier_id)` — 供应商查询

## 3. API 请求/响应模型

### 3.1 ProductCreateRequest — 新建货品请求

继承自 ProductMaster，仅包含创建时可设置的字段（排除审计字段和系统字段）。

**必填字段**: sku_code, name, specification, brand, unit_price, category

### 3.2 ProductUpdateRequest — 更新货品请求

所有字段可选。根据锁定状态决定哪些字段可修改。

### 3.3 ProductListResponse — 列表响应

| 字段名 | 类型 | 说明 |
|--------|------|------|
| total | int | 总记录数 |
| page | int | 当前页码 |
| page_size | int | 每页数量 |
| items | ProductMaster[] | 当前页数据 |
| categories | ProductCategory[] | 可用分类列表 |

### 3.4 ProductStatsResponse — 统计响应

| 字段名 | 类型 | 说明 |
|--------|------|------|
| total_products | int | 货品总数 |
| active_products | int | 激活数 |
| locked_products | int | 锁定数 |
| draft_products | int | 草稿数 |
| total_categories | int | 分类总数 |
| total_suppliers | int | 供应商总数 |
| avg_unit_price | float | 平均价格 |
| category_breakdown | dict | {category_code: count} |

## 4. 枚举值汇总

### 4.1 通用状态枚举

| 枚举名 | 值 | 使用场景 |
|--------|-----|----------|
| **ProductStatus** | draft / pending_approval / active / discontinued | ProductMaster.status |
| **ApprovalStatus** | none / pending / approved / rejected | ProductMaster.approval_status |
| **ChangeStatus** | pending / approved / rejected / cancelled | ChangeRequest.status |
| **SupplierStatus** | active / suspended / blacklisted | SupplierInfo.status |
| **ReceivingStatus** | pending / inspecting / approved / rejected | ReceivingRecord.status |
| **OrderStatus** | draft / submitted / confirmed / partial / received / cancelled | PurchaseOrder.status |
| **QualityGrade** | A / B / C / D | QualityCheckResult.grade |
| **ChangeType** | brand_replace / price_adjust / spec_modify / discontinue / reactivate | ChangeRequest.change_type |
| **CategoryStatus** | active / inactive | ProductCategory.status |
| **SubstituteStatus** | active / expired / cancelled | TemporarySubstitute.status |

## 5. 存储结构

### 5.1 Edge UI JSON 文件存储

```
edge/edge-ui/data/
└── product_master.json    # 主数据文件
```

**文件结构**:
```json
{
  "products": {
    "FP-MW-001": { /* ProductMaster 对象 */ },
    "FP-MW-002": { /* ProductMaster 对象 */ }
  },
  "categories": [
    { /* ProductCategory 对象 */ }
  ],
  "change_requests": [
    { /* ChangeRequest 对象 */ }
  ]
}
```

### 5.2 展会演示数据库

```
demo/data/
└── expo_demo.db           # SQLite (Demo数据)
```

**包含表**:
- demo_scenarios (演示场景配置)
- demo_products (演示货品数据)
