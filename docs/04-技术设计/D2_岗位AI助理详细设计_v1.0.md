## 1. 设计概述

### 1.1 核心价值

> "摄像头替你看后厨，AI 替你算订货，**同一工作台管所有岗位**。"

D2 岗位 AI 助理是火瞳系统的**人机交互层**，将 D1 冻品供应链的数据和能力按角色聚合为个性化工作台。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **角色隔离** | 每个角色只看到与自己相关的内容 |
| **人工确认** | 所有AI建议需人工确认后才执行；关键操作必须留痕 |
| **数据聚合** | 一个页面聚合 D1 全部模块数据（S01/S02/S03/S04） |
| **行动导向** | 每条待办/建议都有明确的"下一步操作"按钮 |
| **Demo友好** | 展会模式下预置完整演示数据，无需真实数据即可展示全流程 |

## 2. 数据模型

### 2.1 AssistantTask（待办事项）

```python
class AssistantTask(BaseModel):
    """AI 助理待办事项"""
    id: str                          # 格式: TSK-YYYYMMDD-NNN
    task_type: TaskType              # 枚举: approval/purchase/inspection/alert/review/action
    title: str                       # 待办标题
    description: str                 # 详细描述
    priority: Priority               # 枚举: urgent/high/medium/low
    status: TaskStatus               # 枚举: pending/completed/dismissed/expired
    source_module: str               # 来源: S01/S02/S03/S04/system
    target_role: Role                # 目标角色: store_manager/chef_head/purchaser/supplier
    action_url: str                  # 跳转链接（如 /receiving-detail.html?id=xxx）
    action_text: str                 # 按钮文字（如"去审批"）
    metadata: Dict[str, Any] = {}   # 扩展数据（如 record_id, order_id）
    created_at: datetime
    due_at: Optional[datetime] = None
    completed_at: Optional[datetime] = None

class TaskType(str, Enum):
    APPROVAL = "approval"            # 需要审批（S02收货审批等）
    PURCHASE = "purchase"            # 需要采购（A03建议下单）
    INSPECTION = "inspection"        # 需要质检（到货提醒）
    ALERT = "alert"                  # 告警（温度异常/供应商预警等）
    REVIEW = "review"                # 需要复盘（日报/周报）
    ACTION = "action"                # 需要执行（SOP纠偏/库存盘点等）

class Priority(str, Enum):
    URGENT = "urgent"                # 🔴 紧急（24h内）
    HIGH = "high"                    # 🟠 高（48h内）
    MEDIUM = "medium"                # 🟡 中（本周内）
    LOW = "low"                      # 🟢 低（信息性）

class TaskStatus(str, Enum):
    PENDING = "pending"
    COMPLETED = "completed"
    DISMISSED = "dismissed"
    EXPIRED = "expired"
```

### 2.2 AssistantSuggestion（AI 建议）

```python
class AssistantSuggestion(BaseModel):
    """AI 生成的智能建议"""
    id: str                          # 格式: SUG-YYYYMMDD-NNN
    suggestion_type: SuggestionType  # 枚举
    title: str                       # 建议标题
    content: str                     # 建议详情（支持Markdown）
    confidence: float                # 置信度 0-1
    data: Dict[str, Any] = {}        # 关联数据（如图表数据源）
    action_type: ActionType          # 可执行动作类型
    action_params: Dict[str, Any] = {}  # 动作参数
    source_role: Role                # 建议目标角色
    source_analysis: str             # 分析依据说明
    created_at: datetime
    expires_at: Optional[datetime] = None
    is_accepted: Optional[bool] = None   # 是否被采纳
    accepted_at: Optional[datetime] = None

class SuggestionType(str, Enum):
    PURCHASE_ORDER = "purchase_order"    # 采购建议
    SUPPLIER_SWITCH = "supplier_switch"  # 切换供应商建议
    INVENTORY_ADJUST = "inventory_adjust"# 库存调整建议
    SOP_CORRECTION = "sop_correction"    # SOP纠偏建议
    COST_OPTIMIZATION = "cost_optimization" # 成本优化建议
    RISK_ALERT = "risk_alert"            # 风险预警
    EFFICIENCY = "efficiency"            # 效率提升建议

class ActionType(str, Enum):
    CREATE_PO = "create_po"           # 创建采购订单
    NAVIGATE = "navigate"             # 跳转页面
    CONFIRM = "confirm"               # 确认操作
    DISMISS = "dismiss"               # 忽略
    CUSTOM = "custom"                 # 自定义
```

#### 备货计算逻辑（简化版）

```python
def calculate_prep_list(base_date: date, products: List[Product]) -> List[PrepItem]:
    """
    基于历史消耗 × 调整因子的备货建议
    - 近7日日均消耗（Demo用固定值）
    - 周末因子: 周六×1.3, 周日×1.2
    - 天气因子: 热天×1.1（预留）
    - 安全系数: ×1.1
    """
    for product in products:
        avg_daily = get_avg_consumption_7d(product.sku)
        weekend_factor = 1.3 if is_saturday else (1.2 if is_sunday else 1.0)
        suggested = avg_daily * weekend_factor * SAFETY_FACTOR
        yield PrepItem(product=product, suggested_qty=suggested)
```

## 5. 业务规则 (BR-D2-01 ~ BR-D2-14)

### 待办生成规则

| ID | 规则 | 条件 | 输出 |
|----|------|------|------|
| BR-D2-01 | 收货审批待办 | S02记录状态=`pending_approval` → 生成 `approval` 类型任务，优先级 `urgent` |
| BR-D2-02 | 订单确认待办 | S03订单状态=`submitted` → 生成 `purchase` 类型任务，优先级 `high` |
| BR-D2-03 | 供应商预警 | S04供应商评分 `<70` 或状态=`probation`/`blacklisted` → 生成 `alert` 任务 |
| BR-D2-04 | D级质检告警 | S02任意项 grade=`D` → 生成 `alert` 任务，优先级 `urgent` |
| BR-D2-05 | 每日日报 | 每日自动生成 `review` 任务（日报查阅），优先级 `medium` |
| BR-D2-06 | 临期预警 | S01商品距临期 `<3天` → 生成 `alert` 任务 |

### AI 建议生成规则

| ID | 规则 | 触发条件 | 建议内容 |
|----|------|---------|---------|
| BR-D2-07 | 采购建议 | 周五/周六自动触发 | 基于近7日消耗 × 周末因子 × 安全系数 |
| BR-D2-08 | 供应商切换 | 主力供应商连续2次C/D级 | 建议切换至备用供应商 |

| BR-D2-10 | SOP纠偏 | 出品率低于目标值>5% | 建议检查对应工序 |
| BR-D2-11 | 库存预警 | 安全库存<3天用量 | 建议紧急补货 |
| BR-D2-12 | 损耗异常 | 日损耗率>10% | 建议排查原因并生成报告 |

## 6. 与 D1 模块联动关系

```
D1-S01 商品主数据 ──→ A02备货清单(引用SKU/名称/单位)
                ──→ A03采购建议(引用价格/规格)
                ──→ A01库存预警(引用安全库存/保质期)

D1-S02 收货质检 ──→ A01待办(approval任务)
               ──→ A01KPI(合格率)
               ──→ A04品质反馈(质检结果)
               ──→ D2建议(D级告警/供应商评分影响)

D1-S03 采购订单 ──→ A01待办(confirm任务)
               ──→ A03订单跟踪(状态/到货)
               ──→ A04待确认订单(新订单通知)
               ──→ D2-KPI(采购额/预算)

D1-S04 供应商 ──→ A01告警(评分下降/黑名单)
             ──→ A03比价表(评分/价格/准时率)
             ──→ A04门户(我的评分/品质反馈)
             ──→ D2建议(供应商切换)
```
